# Contributing to Verso Updated

Thank you for your interest in this community continuation of Verso.

## Project Status

This is an independent fork of the archived [versotile-org/verso](https://github.com/versotile-org/verso) project.  
The original project was archived in October 2025 due to limited resources.

We are working on:

- Modernizing the Servo dependency (incrementally)
- Improving Windows support and documentation
- Eventually providing easier-to-use binaries

## How to Contribute

1. **Open an issue first** for larger changes (if Issues are enabled).
2. Fork this repository.
3. Create a feature branch.
4. Make your changes.
5. Open a Pull Request with a clear description.

## Development Focus (Current Priority)

1. Windows build reliability
2. Controlled Servo version upgrades
3. Documentation quality
4. Stability of basic browsing features

## Code Style

- Follow existing Rust style in the repository.
- Keep commits focused and well-described.
- Do not claim features work if they have not been tested.
